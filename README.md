# 💰 Expense Tracker

A simple **Python Expense Tracker** that allows users to enter multiple expenses and calculates the **total amount spent**.

## 🚀 Features

* Enter multiple expense amounts
* Automatically calculates the total expense
* Simple and beginner-friendly Python program
* Uses loops, user input, and accumulator concepts

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Download or clone the repository.
2. Open the Python file.
3. Run the program.
4. Enter your expenses when prompted.
5. View the total amount spent.

## 📌 Example

```text
Enter number of expenses: 3
Enter expense 1: 100
Enter expense 2: 50
Enter expense 3: 20

Total Spent: 170
```

## 🎯 Learning Objective

This project helps beginners understand **variables, loops, arithmetic operations, user input, and accumulators** in Python.
